# OpenCanvas

An original, Procreate-style drawing app for Android. Built from scratch in Kotlin.

## Build (GitHub Actions)
Push to `main` -> Actions tab -> latest run -> download the `opencanvas-debug-apk` artifact -> install on your device.

## Roadmap
- [x] Phase 1: canvas, pressure, smoothing, pan/zoom, undo/redo, eraser, colors, size
- [ ] Phase 2: layers (opacity, visibility, blend modes)
- [ ] Phase 3: GPU rendering (OpenGL ES), tiled undo, low-latency stylus path
- [ ] Phase 4: brush engine (stamps, spacing, jitter, textures)
- [ ] Phase 5: save/load project (zip + JSON), export PNG/JPEG/PSD
- [ ] Phase 6: selection, transform, fill, smudge, color wheel
